---
title: Perfiles
---

Un perfil indica quién presenta la solicitud y los datos que pueden usar los documentos. **Cada documento se redacta a partir de un perfil y de nada más**, así que incluya lo que usted pueda respaldar: puestos y lo que hizo en ellos, contratos anteriores, programas, resultados con sus cifras.

- Cada paquete tiene sus propios perfiles: una persona para empleos; una organización para licitaciones; una organización o un investigador para subvenciones; un profesional independiente o una empresa para contratos (consulte [Paquetes](../packs/)).
- Un perfil de cada paquete es el **predeterminado**; una solicitud puede usar otro.
- **Cómo deben sonar los documentos** admite instrucciones sencillas, como “frases cortas, sin jerga”.
- Las listas llevan un elemento por línea. En grupos como los contratos anteriores, use **Añadir** para agregar otro y **Quitar** para eliminar uno que no necesite.

### Empezar desde su currículum

En **Nuevo perfil**, use **Elegir un archivo** (o suéltelo en el recuadro): un PDF, un archivo .docx o texto, de hasta 5 MB. El perfil se crea al momento y su modelo rellena los campos a partir del documento: puestos, formación, habilidades y lo demás. Sirve para cualquier paquete: el perfil de licitaciones lee una presentación de capacidades.

- A su modelo se le pide usar solo lo que dice el documento, y lo que no encaja en un campo se deja fuera en lugar de adivinarlo. Aun así puede pasar por alto o leer mal algo, así que **revise cada campo** y guarde.
- La lectura tarda un minuto o dos. Si prefiere escribirlo usted, use **Parar y rellenarlo yo**: lo que escriba nunca se sobrescribe.
- Si su modelo no pudo leerlo, use **Leerlo de nuevo** cuando esté en marcha. Un escaneo sin texto no se puede leer: suba el PDF o el .docx en que se hizo el currículum.
- El archivo se guarda con el perfil: **descárguelo** desde la página del perfil. Al eliminar el perfil se elimina el archivo.

### Un segundo perfil

**Duplicar** copia un perfil, con todo lo que tiene, como uno nuevo que no es el predeterminado. Cambie lo que sea distinto (un resumen para otros puestos, las habilidades que van primero) y guarde; el original queda como estaba.
